# 主历史标签：Flutter 固定宿主与即时快照

更新：2026-11-09。历史主入口已由内嵌Flutter接管，不再通过“Flutter历史”按钮启动独立Activity。保留原生四个根标签、设置的备份恢复和个人Room结构。旧Kotlin历史函数保留作参考，不再参与主入口绘制。

## 首次进入和重进

MainActivity在原生首帧后准备HistoryRepository及HistoryEnginePool；动作库预热错开1500ms，避免同时争抢首屏。历史引擎预热包括真实快照、页面、标准控件及少量premium按钮绘制，Dart准备与原生首帧都确认后才暂停归池。历史和动作库各最多缓存一个闲置引擎，均使用应用上下文，不保留已关闭桥接/宿主Activity；用受限运行时内存换取重进速度，没有添加媒体副本。

HistoryScreen直接在当前MainActivity绑定已准备引擎，列表区域标记排除原生底栏，FlutterView保持固定全屏。图表和选择弹窗共用根Navigator；弹窗捕获全屏触摸、返回和辅助功能，嵌套弹窗全部关闭且退场完成后恢复底层导航。历史路由不再叠加Compose的出入场延迟。

预热完成时，bootstrap直接携带初始快照，首次绘制不再重复查询或显示历史加载转圈。若进程刚启动且预热尚未完成，仍有必要的初始化；不承诺所有设备、任意负载和海量记录均零毫秒。预热失败可回退到正常页面错误/重试，不能让加载异常变成应用崩溃。

## 缓存不是静态备份

HistoryRepository只保存一个应用级不可变快照，后台Room事务读取已提交数据，再由Rust计算图表。监听workout_tasks、weight_records和app_settings失效并合并更新；桥接订阅推送新快照。递增revision防止旧异步消息覆盖新记录。手动下拉刷新强制重读，不只返回旧缓存。快照、版本号和引擎均不进入备份，也不修改个人记录。

## 一级触感与标题

历史列表/图表和管理动作库的我的动作/内置动作库切换，统一使用Android VIRTUAL_KEY系统触感，尊重系统开关。仅实际切换触发，重复点选不重复震动；二级筛选不因此增加反馈。

历史一级菜单固定放到标题下面，标题与菜单高度按实际文字/字体缩放计算，不与标题争宽。内置动作详情标题允许换行，极长标题有可滚动区域；类别单独排在下面。已选动作的玻璃选择框也允许完整换行，不沿用上游GlassPicker的一行ellipsis。正文和操作区保持可达。

## 图表与动作选择

纵坐标文字从左侧开始，坐标轴按最宽刻度文字加8dp确定位置，右边距6dp，不再统一预留50dp。点击定位复用同一plotRect，日期标签约束在绘图范围，避免显示与命中偏离。

动作选择弹窗外边距由24dp减为16dp，操作区间隔由20dp减为8dp，取消按钮保留可触摸高度；内容根据屏高/键盘动态分配，最多560dp。长列表可滚动、可搜索，取消始终可达，不用缩小文字或不合格的触摸目标换行数。

## 验证

Flutter测试覆盖首次快照免二次读取、无加载转圈、版本倒序过滤、标题与菜单分离、长名称、一级震动去重、动态纵轴和键盘/选择器。Android测试覆盖真实Room写入/删除失效更新、预渲染和重进复用，以及原生根历史→AI→历史仍在MainActivity中并复用同一引擎。继续执行原动作库、媒体、历史计算与AI流式回归。
