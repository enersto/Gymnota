# AI 私教：Rust 流解析已接入

更新：2026-11-08。本轮把上一阶段的离线模块接入实际请求。私教界面仍为现有 Compose 页面；Flutter 私教页面和 EventChannel 尚未替换。个人 Room 表结构、备份、模型、地址、照片与导入确认流程保持原职责。

## 当前可以使用的流程

| 流程 | 当前实现 |
| --- | --- |
| 文字问答、带图问答、拍照分析 | 原提示词与附件处理 → 原生 HTTP → Rust SSE/JNI → 增量回答 |
| 周计划建议 | 原目标、周数、部位/场景/伤病与个人历史 → 同一流协调层 |
| 反馈细化为 CSV | 独立流会话，只在完整回答结束后进入原可编辑确认页 |
| 长期记忆摘要 | 独立流会话，只持久化完整正文，不混入正在展示的回答 |
| 连接测试 | 保留原独立非流式测试，不与正式生成混用 |
| 历史查看、删除、重新选用 | 原 Room/界面；重新选用会取消当前生成，防止迟到结果覆盖 |

界面提供“流式回答”开关（当前 ViewModel 会话内有效，不新增数据库配置项），默认开启。关闭后继续用旧 ChatRequest/非流式接口；兼容旧服务时由用户主动关闭并重新发送。收到非 SSE、HTTP 错误或断流后不自动重发 POST。服务不支持流式时展示提示，避免一次失败悄悄产生第二次计费请求。

生成中逐段展示纯文本，完成后切换原 Markdown，避免每个网络碎片重解析全文。更新至多约每40ms发布一次，结束强制刷新；这是发布节流，并非承诺网络每40ms都有数据。保留用户滚动位置，不强行滚到底部。停止生成取消当前 Job/Call，保留已展示片段并标为已停止。

## 跨语言职责

- `RustAiStream.kt`：每个 HTTP 响应拥有一个 AutoCloseable JNI 会话；只传响应字节和协议能力，不传密钥、提示词、照片或 Room 对象。
- `ai_sessions.rs`：受锁保护的最多8个会话，整数ID而非裸指针，关闭幂等、关闭后拒绝访问；每次 JNI 输入最多64KiB。配置受校验，错误后不复用污染解析状态。
- `ai_stream.rs`：UTF-8跨块、BOM、CR/LF、注释、多行data、事件大小、终止与拒答；Chat Completions和Responses事件归一。`error:null`不再误判成服务错误。
- `AiStreamRunner.kt`：保留 Retrofit Call，链接协程取消、关闭响应体、给正文/公开推理分区、限制合计文本长度1,000,000字符，发布请求ID与递增序号的不可变快照。网络错误不把远端错误正文显示或记录为回答。
- `AiService.kt`：`@Streaming @SkipCallbackExecutor`让流读取留在OkHttp工作线程，避免Android默认回调在主线程阻塞。HTTP客户端关闭连接失败自动重试。新请求不擅改用户配置模型，也不强加temperature或stream_options。
- `MainViewModel`：构建原提示词、保留个人名称、合并流状态、控制历史与Room写入。生成代号及状态更新同步，停止/新请求/历史选用使旧回调失效。CSV、记忆和主回答使用不同解析实例。

正文只有非空、未拒答并收到正常stop和终止事件才算完整。缺失终止、length截断、工具调用、服务错误和取消均不能直接作为完整建议导入或自动保存为新回答。非流式兼容路径也拒绝明确的非stop结束；旧服务未返回finish_reason时保留既有兼容行为。已经存储的历史记录可照常重新选用并进入原人工确认流程。

## 推理内容边界

当前实际请求仍为用户原来的 `v1/chat/completions`。默认不假定兼容服务会提供公开推理字段；没有按模型名、地址或正文标签猜测隐藏推理。Rust协调层已离线验证显式声明的公开字段可单独传递，界面也准备了折叠区，但当前页面尚无能力配置入口，因此默认实际请求不采集该字段。

Responses的公开推理摘要解析已保留，独立请求适配器和能力设置仍未接入；不能把Chat请求直接发给Responses。OpenAI可提供的是模型支持并启用后的推理摘要，不能承诺完整内部思维链。

依据：[OpenAI Docs 流式事件参考](https://developers.openai.com/api/reference/resources/chat/subresources/completions/streaming-events)、[流式指南](https://developers.openai.com/api/docs/guides/streaming-responses)、[推理指南](https://developers.openai.com/api/docs/guides/reasoning)。

测试使用假凭证、本地内存拦截器及可控响应体，不请求真实AI服务、不读取真实密钥。覆盖真实Retrofit请求形状与工作线程、完成前可见的增量、中文跨字节JNI、取消关闭与迟到丢弃、截断/拒答/错误、无自动重发、输出上限、空回答、公开推理隔离与并发实例隔离。保留既有动作库、玻璃、历史与媒体回归。
